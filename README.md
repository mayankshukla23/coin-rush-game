# Coin Rush 🪙

A colorful, mobile-friendly 2D endless runner built with vanilla HTML, CSS, and JavaScript. Run, jump, collect coins, dodge obstacles, and clear all 10 handcrafted stages.

## Play

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

### Controls

- **Tap / click / Space / ↑**: jump (double-jump supported)
- **P / pause button**: pause or resume
- **Restart**: restart the current level
- Audio is generated with the Web Audio API, so no asset downloads are needed.

Progress and your best score are saved in `localStorage`.
